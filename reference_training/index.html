GSAPLoss(temperature=0.001, negative_drop_rate=0.9, chunk_size=64)

Bases: SmoothAPLoss

Global sigmoid AP surrogate (gSAP), arXiv:2610.09863.

All valid directed pairs are ranked together, including negatives from queries without positives. Optional negative dropping removes the lowest negative scores and preserves all positives. Defaults follow the paper's distractor-query recipe; set negative_drop_rate=0 for the full loss.

Parameters:

Name Type Description Default

 0.9

Number of positive ranks computed per checkpointed chunk.

 64

Configure global ranking temperature, negative dropping, and chunk size.

SigLIPLoss(scale=10.0, bias=-10.0, learnable=True)

Bases: Module

Sigmoid pairwise objective with a shared learnable scale and bias.

Uses cosine similarities and excludes self-pairs for embedding batches. from_similarity also supports rectangular/cross-modal matrices. The signed logistic loss is summed over valid pairs and divided by the number of queries, as in SigLIP; it is not averaged over all pairs. Negative-only batches still train. No-positive batches behave differently from AP losses.

Initialize the logit scale and bias, optionally making them trainable.

forward(embeddings, labels)

Compute sigmoid pair loss from labeled embeddings, excluding self-pairs.

from_similarity(similarities, positive_mask, valid_mask=None)

Sum signed logistic losses over valid pairs and divide by query count.

SmoothAPLoss(temperature=0.01, chunk_size=64)

Bases: Module

Per-query sigmoid AP surrogate (mSAP).

forward(embeddings, labels) uses cosine similarities and excludes self-pairs. from_similarity(S, Y, valid_mask=None) accepts rectangular similarity/relevance matrices, including cross-modal diagonal positives. Queries without valid positives are omitted from the mean. Empty batches return a differentiable zero. Each rank includes sigmoid(0) = 0.5.

MinedLoss(loss, miner)

Bases: Module

Apply a PyTorch Metric Learning miner before a compatible backend loss.

Both modules are registered so proxies and any trainable loss parameters remain available to the optimizer and checkpoint state.

CombinedLoss(objectives, weights=None)

Bases: Module

Weighted sum of named objective(embeddings, labels) modules.

Weights are stored in checkpoint state. Include this module's parameters in the optimizer to train constituent classifiers, proxies, or scales.

train.ranking

Differentiable per-query and global average precision objectives.

The sigmoid ranks follow Eqs. (3), (8)--(10) of Psomas et al., "Global Average Precision for Representation Learning", arXiv:2610.09863.
